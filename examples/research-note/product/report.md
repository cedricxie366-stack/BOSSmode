# 本地数据备份方案研究

目标：为本地单用户试用选择能保留数据、易于备份的存储方式。

Node.js 24.12.0 提供内置 node:sqlite，DatabaseSync 可以打开磁盘数据库。其 backup API 可对已打开数据库执行备份。该版本文档仍将模块标为开发中，因此需要固定运行版本并保留恢复演练。

建议使用 SQLite 保存业务数据；把代码、业务数据库与 Builder 控制状态的备份分别管理。恢复前展示备份时间与记录范围，并保留当前副本。这是本项目的工程建议。

来源：[Node.js 24.12.0 SQLite 官方文档](https://nodejs.org/download/release/v24.12.0/docs/api/sqlite.html)。

限制：本报告未评估多人同时使用、远程托管或任何真实客户数据；引用完整不等于所有结论已被自动验证。
