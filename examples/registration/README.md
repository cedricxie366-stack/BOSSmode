# 社区活动报名台

一个使用 Node.js 24 内置模块实现的小型中文活动报名应用。活动容量为 2 人：有空位时报名者直接确认，满额后则按提交顺序进入 FIFO 候补名单。取消已确认报名会自动将最早候补者转为确认；取消候补登记只会将该人移出队列。重复邮箱检查覆盖确认与候补名单，且不区分大小写。

所有报名数据仅保存在进程内存中，服务重启后会清空。页面中的活动资料与通知均为模拟内容，不会发送真实邮件或消息。

## 运行

需要 Node.js 24 或更高版本，无需安装依赖：

```bash
npm start
```

然后访问 <http://localhost:3000>。如需指定端口，可设置 `PORT` 环境变量。

## 测试

```bash
npm test
```

测试使用 Node.js 自带的 `node:test`，并让 server factory 绑定临时端口。
