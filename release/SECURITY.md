# 安全与报告边界

本地单用户预览版不是抵御同账户恶意进程的完整沙箱。报名检查依赖 macOS Seatbelt。路径检查不替代宿主权限。

未知结果不自动重试，缺少证据不晋级；记录用户选择不等于付款、发送、发布或上传许可。

不要公开上传秘密、真实客户资料、完整日志或项目数据库。发现疑似泄漏先停止分享相关资料，保留本地证据。安全问题请通过本仓库 Security 页的“Report a vulnerability”私密报告入口提交。若入口暂时不可用，只在 Issues 提交不含漏洞细节与秘密的联系请求，等维护者确认安全渠道后再提供材料；不要把密钥当作复现附件。

扫描仅检测已声明的常见风险模式，不能保证识别全部秘密。DSH 使用独立工具进程，并遵循当前宿主权限；MCP工具自身的文件范围检查不是完整操作系统沙箱。模型仍可能绕过流程使用宿主原生文件工具，不能把技能提示词说成不可绕过的安全锁。
